# Руководство по установке GrokSniper на новом компьютере

Данное руководство описывает пошаговый процесс развертывания торгового бота GrokSniper на новом устройстве (с операционной системой Windows, Linux или macOS).

## 1. Предварительные требования

Перед началом установки убедитесь, что на компьютере установлены следующие программы:
- **Git** (для клонирования репозитория)
- **Python 3.10** или выше (для работы бэкенда)
- **Node.js 18+** и **npm** (для работы фронтенда)
- **PostgreSQL** (база данных)

## 2. Клонирование репозитория

Откройте терминал (PowerShell или командную строку) и выполните:
```bash
git clone https://github.com/kotelyanets/GrokSniper.git
cd GrokSniper
```

## 3. Настройка Базы Данных (PostgreSQL)

1. Убедитесь, что служба PostgreSQL запущена.
2. Создайте новую базу данных для бота (например, `sniper_db`).
3. Создайте пользователя (или используйте стандартного `postgres`) и задайте пароль.
4. Запомните URL подключения (например: `postgresql+psycopg2://postgres:password@localhost:5432/sniper_db`).

## 4. Настройка Бэкенда (Python)

Бэкенд отвечает за торговую логику, работу с биржами (Binance), ИИ-агентами (Grok/Groq) и Telegram.

1. Перейдите в корневую папку проекта.
2. Создайте виртуальное окружение:
   ```bash
   python -m venv backend/venv
   ```
3. Активируйте виртуальное окружение:
   - На Windows: `.\backend\venv\Scripts\activate`
   - На Linux/macOS: `source backend/venv/bin/activate`
4. Установите зависимости:
   ```bash
   pip install -r backend/requirements.txt
   ```
5. Настройте переменные окружения:
   - Скопируйте файл `.env.example` и переименуйте его в `.env` (в корневой папке проекта).
   - Заполните необходимые ключи в файле `.env`:
     - `DATABASE_URL` (ваша строка подключения к PostgreSQL)
     - `BINANCE_API_KEY` и `BINANCE_API_SECRET`
     - `TELEGRAM_BOT_TOKEN` и `ALLOWED_TELEGRAM_ID`
     - `GROQ_API_KEY` или `GROK_API_KEY` (для ИИ-аналитики)

6. Запустите сервер бэкенда:
   ```bash
   python -m backend.src.main
   ```
   *(При первом запуске SQLAlchemy автоматически создаст все необходимые таблицы в базе данных).*
   *Сервер запустится на порту `http://localhost:8000`.*

## 5. Настройка Фронтенда (Next.js)

Фронтенд — это дашборд управления ботом и лаборатория визуального бэктеста.

1. Откройте новое окно терминала.
2. Перейдите в папку фронтенда:
   ```bash
   cd frontend
   ```
3. Установите NPM-зависимости:
   ```bash
   npm install
   ```
4. Запустите фронтенд-сервер:
   ```bash
   npm run dev
   ```
   *Интерфейс будет доступен по адресу `http://localhost:3000`.*

## 6. Проверка работоспособности

1. Откройте в браузере `http://localhost:3000`. Вы должны увидеть рабочий дашборд.
2. Перейдите на вкладку **Visual Backtesting Laboratory** (`/backtest`), чтобы убедиться, что связь с бэкендом установлена (попробуйте запустить тестовый бэктест на исторических данных).
3. Напишите `/start` вашему Telegram-боту, чтобы проверить работу Telegram-интерфейса и получение уведомлений.
